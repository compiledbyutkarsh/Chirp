# 🐦 Chirp — Full-Stack Social Media Platform

A professional Twitter clone built with the MERN stack featuring real-time feed, authentication, direct messages, notifications and more.

## ✨ Features
- 🔐 JWT Authentication (Login / Register)
- 🐦 Post chirps with text & images
- ❤️ Like, 🔁 Retweet, 💬 Comment
- 📌 Bookmark tweets
- 🔔 Notifications (likes, retweets, follows, comments)
- 💬 Direct Messages
- 👤 Profile pages with follow/unfollow
- ✏️ Edit profile (name, bio, avatar, cover image)
- 🔍 Search users

## 🛠️ Tech Stack
| Layer | Technology |
|---|---|
| Frontend | React.js, Vite, Tailwind CSS, Zustand |
| Backend | Node.js, Express.js |
| Database | MongoDB Atlas, Mongoose |
| Auth | JWT, bcryptjs |

## 🚀 Setup & Run

### 1. Clone
```bash
git clone https://github.com/compiledbyutkarsh/Chirp.git
cd Chirp
```

### 2. Backend
```bash
cd server
npm install
npm run dev
```

### 3. Frontend
```bash
cd client
npm install
npm run dev
```

### 4. Open
```
http://localhost:5173
```
